The two notebooks here provide examples on how to use the components for integrating GFM and SFINCS, and how to configure and run the workflow. The example provided here is for the storm Babet along the German Baltic coast in October 2023.

The notebook `create_sfincs.ipynb` guides a user through the process of configuring a SFINCS model for the area. The notebook `run_breach_scenarios.ipynb` defines and runs various scenarios by updating the SFINCS model with local weather data, and adding breaches to dikes. It will also run the GFM for the event and perform a comparison between GFM and SFINCS. The final outputs of the workflow as defined in the notebook are floodmaps from both sources, a summary statistics of the comparison, and a validation plot for SFINCS. The necessary data for this use-case can be found on the interTwin datalake using Rucio, under the scope `wtromp:baltic_usecase`. The script `download_data.py` will download this data from Rucio and arrange the files that currently fits the notebooks, though the user is free to organize the data how they see fit provided they adapt the paths in the notebooks accordingly.
